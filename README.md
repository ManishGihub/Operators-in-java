# Operators in Java

## 1. Arithmetic Operators
| Operator | Description        |
|----------|--------------------|
| `+`      | Addition           |
| `-`      | Subtraction        |
| `*`      | Multiplication     |
| `/`      | Division           |
| `%`      | Modulus (Remainder)|

## 2. Relational Operators
| Operator | Description              |
|----------|--------------------------|
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |

## 3. Logical Operators
| Operator | Description |
|----------|-------------|
| `&&`     | Logical AND |
| `||`     | Logical OR  |
| `!`      | Logical NOT |

## 4. Assignment Operators
| Operator | Description              |
|----------|--------------------------|
| `=`      | Assign                   |
| `+=`     | Add and assign           |
| `-=`     | Subtract and assign      |
| `*=`     | Multiply and assign      |
| `/=`     | Divide and assign        |
| `%=`     | Modulus and assign       |

## 5. Bitwise Operators
| Operator | Description        |
|----------|--------------------|
| `&`      | AND                |
| `|`      | OR                 |
| `^`      | XOR                |
| `~`      | NOT (Complement)   |
| `<<`     | Left Shift         |
| `>>`     | Right Shift        |

## 6. Unary Operators
| Operator | Description     |
|----------|-----------------|
| `++`     | Increment       |
| `--`     | Decrement       |

## 7. Increment & Decrement Types

- **Pre-Increment (`++a`)** → Increments value before using it  
- **Post-Increment (`a++`)** → Uses value first, then increments  

- **Pre-Decrement (`--a`)** → Decrements value before using it  
- **Post-Decrement (`a--`)** → Uses value first, then decrements
