# Operators-in-java
These are the operators in java

Arithmetic Operators => +,-,/,*.%
Relational Operators => >,<,>=,<=,==,!=
Logical Operators    => &&,||,!
Assignment Operators => =,+=,-=,*=,/=,%=
Bitwise Operators    => &,|,^,~,<<,>>
Unary Operators      => ++,--

Pre Increment(++a) and Post Increment(a++)
Pre Decrement(--a) and Post Decrement(a--)
